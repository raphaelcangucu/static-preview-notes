# UX 2026 Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the visual language of `Macro-Markets/world-cup-2026-simulator` to all seven Astro documents without changing their content, routes, or access-state semantics.

**Architecture:** Tailwind 4 remains the styling engine. Reference tokens become semantic CSS variables in the global layer; Astro shared components own shell-level patterns; existing page sections retain copy while focused page CSS maps them into the shared visual system.

**Tech Stack:** Astro 7, Tailwind CSS 4, TypeScript 6, Vitest 4, Cheerio.

## Global Constraints

- Keep all seven explicit Astro routes and complete content.
- Do not use legacy HTML imports, `set:html`, iframe, or client JavaScript for static UI.
- Keep `noindex`, `robots.txt`, and the GitHub Pages base path.
- Active is solid green; Partial is dashed blue; Locked is dotted amber; Absent is ghost gray; Premium is dark.
- Meet WCAG AA and honor `prefers-reduced-motion`.
- Do not use assets from the reference because it has no license file.
- Never run `npm run dev`; inspect built output with a temporary static server.
